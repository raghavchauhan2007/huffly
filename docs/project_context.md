# Huffly

## Goal

Interactive Huffman compression platform built around my own Huffman encoder/decoder written in C.

## Current Status

Design Phase

## Tech Stack

### Backend

- Bun
- JavaScript
- MongoDB

### Frontend

- HTML
- Tailwind CSS
- Vanilla JavaScript

### Native Binary

- Precompiled `huff2412`

## Decisions

- One Git repository.
- Separate frontend and backend directories.
- Bun native server (no Express).
- API prefix: `/api/v1`
- UUID workspace per request.
- Deployment with Podman (later).
